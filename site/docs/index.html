Nivora documentation

Install it, call the API, understand how it works. Everything here is built from the Markdown in the repository.

  • Installing NivoraRequirements: macOS 15 or later, Apple silicon.
  • Widget and ShortcutsNivora ships a read-only WidgetKit widget and two App Intents. They show only what the app has already measured.
  • APIAll /v1/ requests use Authorization: Bearer $NIVORA_TOKEN when a token is configured. The local server uses constant-time bearer comparison, rejects unapproved browser origins, ser
  • ArchitectureNivora 0.2 separates collection, normalization, intelligence, storage and presentation while keeping the collector dependency-free.
  • FluxVM integrationFluxVM is a first-class Nivora context source, not just another process name.
  • Packet captureCapture is an opt-in, per-session feature. Everything else in Nivora stays payload-free.
  • NetworkExtension integrationNivora uses Apple's content-filter APIs rather than attempting to port Linux eBPF to macOS.
  • ChangelogRelease notes for Nivora, the macOS network intelligence app.
